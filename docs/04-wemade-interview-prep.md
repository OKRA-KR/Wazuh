# 위메이드 면접 대비 (인프라보안/블루팀) — 금요일

> 이 문서 하나로 면접장 직전까지 복습 가능하게 구성. 답안은 **완성문이 아니라 키워드** — 읽지 말고 네 말로 바꿔서 소리내어 연습할 것.
> 면접 절차(일반): 서류 → 1차(실무자) → 2차(임원). 분위기는 자유로운 편, 태도·진중함·포트폴리오 숙달도 봄.

---

## 0. 핵심 포지셔닝 (모든 답의 밑바탕)

> **"저는 공격이 성립하는 경로를 찾는 진단자(레드팀)이면서, 그걸 탐지·모니터링하는 블루팀 도구를 직접 세워본 사람입니다."**

위메이드는 지금 **탐지·진단 역량이 절실한 회사**다(아래 §1). 요기요에서 약점이던 것들이 여기선 강점으로 뒤집힌다.

---

## 1. 회사 상황 — 반드시 알고 갈 것 (숙제했다는 신호)

**위메이드는 최근 반복적 보안사고를 겪었다:**
- **2026년 7월**: WEMIX$ 스마트컨트랙트 **관리자 권한 탈취** → 522만개 부정발행, **약 77억원** 피해. **근본원인 = 2022년에 심긴 4년 묵은 코드 취약점.**
- **2024~2025년**: 브릿지 해킹 피해 (반복 사고).
- **대응**: 디지털자산 보안체계 전면 강화, **공개키/개인키 전면 교체**, **네트워크 망분리 강화**.
- 블록체인 매출 비중은 작지만(연 100억대) 박관호 대표가 밀고 있는 전략 사업 → 신뢰도 타격이 뼈아픔.

**이게 왜 너한테 유리한가:**
| 그들의 아픔 | 너의 무기 |
|---|---|
| 4년 묵은 코드 취약점을 못 잡음 | OKRA = 코드 취약점 자동 진단(SAST) + **성립검증으로 진짜만 걸러냄** |
| 사고를 늦게 인지 | Wazuh SIEM 직접 구축 → 탐지·모니터링·오탐튜닝 경험 |
| 망분리·키관리 강화 중 | 진단자로서 공격 경로를 알아 방어 설계 관점 제시 가능 |

> **역질문·자기어필의 축:** "최근 보안 사고 이후 탐지/모니터링 체계를 어떻게 보강하고 계신지 궁금합니다. 저는 진단과 SIEM 탐지 양쪽을 경험해서 그 지점에 기여하고 싶습니다." (숙제+겸손+연결 한 방)

## 2. 요기요 3패착 → 위메이드 처방

**① AI SAST 꼬리질문 어버버**
- 원인: "만들었다"까진 됐는데 **설계 결정의 근거**를 깊이 못 따라감.
- 처방: OKRA 결정 3~4개를 "문제→그래서 이 방식" 카드로 고정(§3 심화 참고). **순서를 외워** 꼬리질문 나오면 카드 순서대로.

**② 성립검증 설명 미흡**
- 처방: 이게 위메이드 **킬러 답변**. "탐지가 진짜냐(오탐)를 거르는 것" = SIEM 룰 튜닝과 같은 논리. §3에 한 문장 카드.

**③ 클라우드 무지**
- 위메이드는 게임 인프라라 온프레미스+클라우드 혼재. **"아예 모른다"는 금지.** 최소 라인(§3 기초 8번)은 준비. 대신 **망분리/네트워크 보안**으로 화제를 네 강점 쪽으로.

## 3. 예상질문 + 키워드 답안

> 형식: `* 질문` / `- 키워드`. 결론 먼저, 근거 2개로 끊기.

### 직무 — SIEM/관제 (JD 핵심)

* SIEM 써보셨나요?
- Wazuh 직접 구축, 에이전트-매니저-인덱서-대시보드
- SSH 브루트포스 탐지, MITRE T1110 매핑 확인
- 오탐 룰 튜닝(local_rules.xml, 레벨 조정·억제)
- 솔직히 운영경험 아닌 실습, 근데 구조·탐지·튜닝은 손으로

* (킬러) 오탐 많은데 어떻게 줄이나요?
- 결론: 조건 좁히기 / 정상행위 억제 / 중요이벤트 격상
- 실제 사례: SSH만 테스트했는데 대시보드에 Email Collection 폭증
- 확인해보니 공격 아니라 고장난 postfix 로그 노이즈가 오분류된 오탐
- full_log 역추적으로 근본원인 식별 → 근본제거(서비스중지) or 룰 억제
- "많이 뜨는 알림 ≠ 중요 위협" 직접 겪음

* 로그 분석 경험은?
- 진단자로서 공격 성립 경로 앎 → 로그에서 흔적 역추적 관점
- Wazuh full_log로 "이 로그 한 줄 → 이 알림" 추적 실습
- 디코더(필드추출)→룰(조건매칭)→레벨판정 파이프라인 이해

* 탐지 룰 직접 만들 수 있나요?
- local_rules.xml에 억제/격상 룰 작성
- if_sid/if_matched_sid 체이닝, frequency+timeframe로 브루트포스 판정
- 읽는 것뿐 아니라 조건 좁혀 새 룰 작성

* Security events랑 설정점검(SCA) 차이?
- 전자: 실시간 로그(행위), 룰엔진이 판정
- 후자: 주기적(12h) 상태 스냅샷, 에이전트가 자체 판정 후 보고, CIS 벤치마크
- 사후탐지 vs 사전하드닝 두 축

### 기초 — 네트워크/시스템/보안

* 침해사고 대응(IR) 경험?
- 결론: 운영 IR 경험 없음(솔직히)
- 다만 진단자로 공격 경로 알아 로그 역추적 관점 있음
- 탐지→분류→원인추적까지 랩에서 사이클 경험

* MITRE ATT&CK이 뭔가요?
- 공격 기법을 표준 언어로 분류한 프레임워크
- Tactic(왜/목적) vs Technique(어떻게), T-번호
- 예: T1110 Brute Force. 탐지를 표준으로 소통·매핑

* 망분리가 뭔가요? (위메이드 대응책이라 나올 수 있음)
- 업무망/인터넷망/운영망 물리·논리 분리로 공격 확산 차단
- 침투해도 측면이동(lateral movement) 제한
- 위메이드도 사고 후 망분리 강화 → 관련 관심 어필

* (클라우드 최소라인) 클라우드 보안 아시나요?
- 결론: 실무 경험은 없습니다. 다만 개념은 이렇게 접근합니다
- 책임공유모델(제공자 vs 사용자), IAM 최소권한, 보안그룹/네트워크 ACL
- 온프레미스 진단 경험을 클라우드 자산으로 확장 학습 중
- (절대 "아예 모른다" 금지)

### 심화 — OKRA / 진단 (강점, 꼬리질문 대비 카드 고정)

* AI SAST 도구를 만들었다는데 설명해주세요.
- 결론: 2계층 구조. 1계층 룰 엔진, 2계층 성립검증/상관분석, 3계층 LLM 트리아지
- 문제: 룰만으론 오탐 폭증 → 그래서 성립검증 계층 추가
- 문제: SAST가 찾은 취약점이 실제 공격으로 이어지나 확인 필요 → DAST 라우트 브리지로 연결

* (꼬리) 성립검증이 정확히 뭔가요? ← 요기요 패착, 여기서 확실히
- 결론: "이 취약점이 실제로 악용 가능한가"를 검증해 오탐을 거르는 것
- 예: SQL 구문이 코드에 있어도 실제 주입점까지 도달·실행되는지 확인
- 도달 못 하면 오탐 → 제외. 이걸로 노이즈 걷어냄
- **연결: SIEM 룰 튜닝도 같은 논리 — "이 로그가 진짜 공격이냐"를 검증**

* (꼬리) 왜 LLM을 3계층으로 뺐나요?
- 결론: 오프라인/폐쇄망 이식성 때문. LLM은 선택적
- 1~2계층은 stdlib만으로 폐쇄망에서 돌게, LLM 없어도 동작
- LLM은 최종 트리아지 보조로만 → 환경 의존 최소화

* 위메이드 최근 사고(4년 묵은 코드 취약점) 어떻게 보나요?
- 결론: SAST/진단으로 사전에 잡을 수 있는 유형
- 오래된 코드일수록 정적분석 정기 스캔 + 성립검증으로 진짜 위험만 추림
- 탐지(SIEM)로 관리자권한 변경 같은 이상행위 실시간 경보도 병행

## 4. 정직 원칙 (절대 규칙)

- 없는 경험 지어내지 않기. 미경험 = "경험 없습니다, 다만 접근은…"
- "실습"을 "운영 경험"으로 포장 금지. (요기요에서 정직이 통했던 방식 유지)
- 과장 직함/자격 금지. 한 일을 그대로.
- 전 직장 험담 금지.
- **기술 면접관에겐 어설픈 아는 척보다 정직한 인정이 신뢰를 준다.**

## 5. 말하기 코칭 (어버버 방지)

- **모든 답: 결론 한 문장 → 근거 2개 → 끝.** 어버버는 "정리 안 된 채 많이 아는 것"이 원인.
- 절었을 때 복구 문장 1개 고정: **"잠시만요, 정리해서 말씀드리겠습니다."**
- 잘 보이려 늘어뜨리지 말고 끊어라.
- 강점 주제(OKRA/성립검증/SIEM) 꼬리질문 = 준비된 카드다. **순서 고정**해서 어버버 차단.
- 자기소개는 통암기 X, 앵커 5개 O. 첫 문장만 토씨까지.
- 눈으로 읽지 말고 **소리내어** 연습.

## 마지막 한 줄
요기요는 제품보안(SAST 깊이)이었고, 위메이드는 **인프라보안(탐지+진단)**이다. 너의 SIEM 실습과 진단 배경이 이 회사의 지금 상황(반복 사고→탐지 강화)에 정확히 맞다. 겸손하되, 이 연결고리는 자신있게.
